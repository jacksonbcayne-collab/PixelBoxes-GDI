# Pixel Boxes GDI

Pixel Boxes is a Windows GDI simulation.

## v1.2.0

- Separate NORTH and SOUTH boxes
- One pixel person in each box
- Four-sided magnets
- Doors
- Windows
- Platforms
- Spring pads
- Ladders
- Stairs
- Box collision
- Mouse dragging
- Reset with R
- ESC to close
